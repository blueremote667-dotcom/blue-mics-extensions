# Click CSS Inspector

Click any element on a page to see its tag, classes, and key computed CSS
properties, without opening full DevTools.

## Load it
1. Unzip this folder.
2. Go to `chrome://extensions`, enable **Developer mode**.
3. Click **Load unpacked**, select this folder.

## How it works
- Click the extension icon, then **Enable Inspector**.
- Hover the page — a pink outline follows your cursor.
- Click an element to lock in its info in the bottom-right panel
  (display, position, size, color, background, font, margin, padding, border).
- Click the extension icon again (or the ✕ on the panel) to turn it off.
